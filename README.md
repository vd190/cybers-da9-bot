# 🛒 Cybers DA9 — بوت المتجر والحماية

بوت واحد متكامل يبني السيرفر كامل بأمر واحد، ويشغّل المتجر والحماية والسجلات.

---

## ⚡ التشغيل (مرة وحدة بس)

### 1) سوّ السيرفر
في ديسكورد ➜ **+** ➜ *Create My Own* ➜ أي اسم (البوت بيغيره لـ **Cybers DA9** ويحط الصورة تلقائياً).

### 2) سوّ البوت
1. ادخل https://discord.com/developers/applications ➜ **New Application** ➜ سمّه `Cybers DA9`
2. من **Bot**:
   - حط صورة البوت: `assets/icon.png`
   - اضغط **Reset Token** وانسخ التوكن (لا تعطيه لأحد أبداً!)
   - فعّل **SERVER MEMBERS INTENT** و **MESSAGE CONTENT INTENT**
   - طفّي **PUBLIC BOT** (عشان محد غيرك يقدر يضيفه)

### 3) آيدي السيرفر
ديسكورد ➜ الإعدادات ➜ Advanced ➜ فعّل **Developer Mode** ➜ كليك يمين على السيرفر ➜ **Copy Server ID**

### 4) ملف `.env`
انسخ `.env.example` وسمّه `.env` وحط فيه:
```
TOKEN=التوكن
GUILD_ID=آيدي السيرفر
```

### 5) شغّل البوت
- **ويندوز:** دبل كليك على `start.bat`
- أو: `npm install` ثم `npm start`

يحتاج [Node.js](https://nodejs.org) نسخة 20.12 أو أحدث.

أول تشغيل بيطبع لك **رابط دعوة** — افتحه وأضف البوت للسيرفر (صلاحية Administrator).

### 6) ارفع رتبة البوت لفوق ⚠️ مهم
إعدادات السيرفر ➜ Roles ➜ اسحب رتبة البوت **لأعلى القائمة**. بدون هذا الحماية ما تقدر تعاقب.

### 7) جهّز السيرفر
في أي روم اكتب:
```
/setup reset:True
```
واضغط **ابدأ التجهيز**. البوت بيحذف الرومات الافتراضية ويبني كل شي، والتقدم يوصلك بالخاص.

### 8) أضف منتجاتك
```
/product add name:اسم المنتج price:25 ر.س description:الوصف | سطر ثاني image:(صورة)
```

### 9) عدّل طرق الدفع
افتح `config.js` ➜ عدّل `payments` ➜ أعد تشغيل البوت ➜ اكتب `/panels`

### 10) أمان إضافي (موصى فيه بقوة)
- فعّل **التحقق بخطوتين (2FA)** على حسابك في ديسكورد
- إعدادات السيرفر ➜ Safety Setup ➜ فعّل **Require 2FA for moderator actions**

## 🛡️ الحماية
| النظام | وش يسوي |
|---|---|
| **Anti-Nuke** | أي أحد غيرك (أو بوت مو بالقائمة البيضاء) يحذف/ينشئ روم أو رتبة، يبند، يطرد، يسوي Webhook، يضيف بوت، يعدل السيرفر أو يعطي رتبة إدارية ➜ **يتسحب منه كل شي ويتبند فوراً** والشي اللي خربه **يرجع تلقائياً** (الروم/الرتبة/الصلاحيات/الرسائل الثابتة). حتى البوتات الموثوقة لها حد أقصى. |
| **Anti-Raid** | دخول 7 حسابات خلال 15 ثانية ➜ وضع طوارئ: طرد أي داخل + مستوى تحقق أعلى، يتوقف تلقائياً بعد 15 دقيقة |
| **Anti-Alt** | الحسابات الأحدث من 7 أيام تنطرد تلقائياً |
| **التحقق (Captcha)** | محد يشوف المتجر إلا بعد ما يكتب رمز التحقق |
| **Anti-Spam** | سبام سريع، تكرار، منشن جماعي، رسائل طويلة ➜ حذف + تايم أوت + تحذير |
| **Anti-Links** | روابط الدعوات ممنوعة دائماً، وباقي الروابط ممنوعة للأعضاء (مسموحة داخل التذاكر) |
| **Anti-Scam** | منع روابط النيترو المزيفة وروابط سرقة الحسابات والـ IP loggers |
| **Anti-Impersonation** | أي أحد اسمه فيه Admin / Support / إدارة / Cybers ... يتغير اسمه تلقائياً |
| **Discord AutoMod** | 4 قواعد رسمية: سبام، منشن، كلام بذيء، دعوات واحتيال |
| **التحذيرات** | 3 تحذيرات = تايم أوت 24 ساعة |
| **Lockdown** | `/lockdown` يقفل الكتابة والصوت بالسيرفر كامل بضغطة |

## 📜 السجلات (Logs)
`🚨 الحماية` • `🔨 العقوبات` • `💬 الرسائل` (حذف/تعديل/حذف جماعي) • `👥 الأعضاء` (دخول/خروج/تحقق/تغيير أسماء) • `⚙️ السيرفر` (كل تعديل ومين سواه) • `🔊 الصوت` • `🎫 التذاكر` (مع نسخة كاملة من المحادثة) • `📦 الطلبات`

## 🛒 دورة الشراء
1. العميل يضغط **🛒 شراء** تحت المنتج ➜ تنفتح له تذكرة خاصة
2. ترسل له تفاصيل الدفع داخل التذكرة ويرسل الإثبات
3. تسلّمه وتضغط **✅ تم التسليم** ➜ ينسجل الطلب في سجل الطلبات
4. العميل يقيّم ⭐ ➜ ينزل تقييمه في روم التقييمات (تقييمات حقيقية بس — ما يقدر يقيّم إلا اللي اشترى)
5. **🔒 إغلاق** ➜ نسخة من المحادثة تنحفظ في السجل وتنرسل للعميل

|---|---|

| `/product add / edit / status / remove / list` | إدارة المنتجات |
| `/announce` | إعلان مع صورة ومنشن اختياري |

| `/warn` `/warnings` `/clearwarns` | التحذيرات |
| `/clear` `/lock` `/unlock` `/slowmode` | إدارة الرومات |
| `/lockdown` `/unlockdown` `/raidmode` | الطوارئ |

### ⚠️ إذا بتضيف بوت ثاني
أضفه أنت (الأونر) وبعدها اكتب `/whitelist add user:@البوت` — وإلا أول ما يسوي أي تعديل بيتبند.

## 🖥️ التشغيل 24/7
البوت يشتغل بس وجهازك شغال. عشان يشتغل دايماً حطه على **VPS** أو استضافة بوتات ديسكورد (ارفع المجلد كامل ما عدا `node_modules` وشغّل `npm install && npm start`).

## ⚙️ التخصيص
كل الإعدادات في `config.js`: الألوان، أسماء الرتب، طرق الدفع، أنواع التذاكر، حدود السبام والرايد، عمر الحساب، الكلمات الممنوعة.

البيانات (المنتجات، الطلبات، التحذيرات...) تنحفظ في `data/` — **خذ منها نسخة احتياطية**.
